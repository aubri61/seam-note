# 트러블슈팅

프론트엔드·백엔드 개발 중 발견한 문제와 근거가 있는 예상 문제를 기록한다. 해결된 버그뿐 아니라 성능·접근성·환경 문제와 아직 조사 중인 문제도 포함한다.

## 작성 방법

1. 기존 기록에서 같은 문제가 있는지 확인한다.
2. 신규 문제는 `_template.md`를 복사해 `YYYY-MM-DD-영역-문제요약.md`로 작성한다. 영역은 `frontend`, `backend`, `shared` 등을 사용한다.
3. 발견 즉시 증상·영향·재현 조건 또는 예상 근거를 기록한다. 조사와 개선 과정에서 문서를 갱신한다.
4. 개선한 내용과 검증 결과, 남은 문제를 기록하고 아래 목록에 링크를 추가한다.

미리 예상한 문제는 발생한 문제와 구분한다. 확인하지 않은 원인은 추정으로, 측정하지 않은 항목은 미측정으로 표시한다. 프레임 드롭, 로딩·레이아웃 지표, 렌더링·메모리, API·DB 성능 문제도 같은 방식으로 기록한다.
