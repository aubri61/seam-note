## 두 탭 / revision / token

20회, 경쟁40attempt /20commit /20CAS거부 /비CAS실패0. 두 메모리 입력 모두 유지20/20이나 DB는 승자만 저장한다. 큰revision+staleToken20회, 최신token+낮은revision20회도 모두 거부. 전체80요청/20commit/60예상거부.

승자20개의 마지막 session.edit→commit p50/p95/p99(ms): 3.9 / 5.6 / 6.5. 이 측정은 debounce를 기다리지 않고 명시flush하며, DOM input latency와 합치지 않는다. 패자는 commit이 없어 latency가 null이다.
